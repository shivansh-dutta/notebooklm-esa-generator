# NYSDEC Part 375 Soil Cleanup Objectives (SCOs)

> **IMPORTANT:** Numeric SCO values in the tables below are representative values from the Part 375 regulations. Always verify against the current promulgated tables at the NYSDEC website (dec.ny.gov) before using specific values in a Phase 1 or Phase 2 report. NYSDEC periodically updates SCO tables.

---

## Purpose

6 NYCRR Part 375 establishes the State's environmental remediation programs, including the Brownfield Cleanup Program (BCP), State Superfund Program (SSF), and Voluntary Cleanup Program (VCP). Soil Cleanup Objectives (SCOs) are the numeric soil concentration limits established under Part 375 that define when soil contamination has been remediated to the level required for a given land use.

**SCO exceedance is relevant to Phase 1 ESA in the following ways:**
1. If known soil data from a prior Phase 2 ESA or remedial investigation at or near the subject property shows concentrations above SCOs, the site may still constitute a REC, CREC, or HREC depending on regulatory status
2. If an off-site source has contaminated soils that exceed SCOs in the direction of the subject property, it may contribute to a REC for the subject property
3. SCO tier selection must match the subject property's current and planned land use (unrestricted, residential, commercial/industrial)

**Relationship to ASTM E1527-21 Classifications:**
- Site with contamination above SCOs and open regulatory status → **REC**
- Site with contamination above SCOs, addressed with institutional controls (unrestricted use SCOs not met, restricted use SCOs met) → **CREC**
- Site with contamination formerly above SCOs, closed at unrestricted use SCOs without controls → **HREC**

## How to Use SCOs in Phase 1 Classification

1. **Known soil data available**: If prior Phase 2 data exists for the subject property or nearby properties, compare reported concentrations to the appropriate SCO tier. Exceedances inform REC/CREC/HREC classification.

2. **Off-site source**: If a nearby facility has documented contamination exceeding SCOs and is upgradient/adjacent to the subject property, this may constitute a REC for the subject property depending on migration pathway.

3. **Land use tier selection**: Match the SCO tier to the subject property's current and intended use. A site that meets commercial SCOs but not unrestricted SCOs requires institutional controls (typically a CREC).

4. **Interaction with DER-10**: NYSDEC Spill Program NFAR closures are based on meeting applicable SCOs at the time of closure. If current SCOs are more stringent than when the NFAR was issued, PE judgment is needed regarding HREC vs. CREC classification.
